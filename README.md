# Acumatica Developer Guide

This repository contains my practice code and learning progress as I work through the Acumatica 2026 R1 developer training guides.

My goal is to strengthen my Acumatica development skills through hands-on exercises and prepare for the Application Developer certification.

## Topics

- Maintenance forms and data access classes (DACs)
- DAC and graph extensions
- Master-detail relationships and data entry forms
- Setup forms, validation, and numbering
- Actions and asynchronous operations
- Workflows and processing forms
- BQL queries and inquiry forms
- Modern UI development with HTML and TypeScript

## Training guides

T200, T210, T220, T230, T270, T240, T250, T290, and Stay Current 2026: Application Developer.

I will add my implementation as I complete each guide, using a course branch for work in progress and merging completed work into `main`.
